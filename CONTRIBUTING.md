# Contributing

Use a focused pull request with a clear problem statement and validation.
Run the relevant unit, engine and UI checks before submitting changes.
Keep generated builds, credentials, personal documents and machine-specific
configuration out of the repository.

Luma Kit is shared with other Luma applications. Update its complete qualified
snapshot and provenance together rather than introducing a second styling
implementation. Contributions use the repository’s license defaults and
Developer Certificate of Origin sign-off (`git commit -s`).
